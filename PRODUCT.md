# Product

## Register

product

## Users

Developers who use multiple coding-agent providers and need to supervise implementation work without losing context across terminals, provider CLIs, or nested agent sessions.

## Product Purpose

V3 Code is a focused desktop and web workspace for working with coding agents. It makes the main conversation, repository state, provider activity, and sub-agent orchestration visible in one place. Success means users can understand who is working, what each agent is doing, and where attention is needed without interrupting the coding flow.

## Brand Personality

Focused, nocturnal, and quietly cyberpunk. The product should feel technically capable and distinctive while remaining calm enough for long coding sessions.

## Anti-references

Avoid glossy gamer branding, loud neon tubes, rainbow gradients, excessive bloom, ornamental circuit-board motifs, and generic AI-dashboard decoration. The superseded V3 icon with chrome-like lettering, code chevrons, and intense magenta glow is an explicit anti-reference.

## Design Principles

- Keep the interface subordinate to the developer's work.
- Make agent identity, provider, status, and hierarchy immediately legible.
- Earn visual personality through restrained, consistent details rather than decoration.
- Preserve familiar coding-tool interactions and information density.
- Treat cross-provider behavior as a first-class product capability, not a special case.

## Accessibility & Inclusion

Preserve keyboard-first operation, visible focus states, reduced-motion behavior, and readable contrast in both light and dark themes. Status must never be communicated by color alone.
